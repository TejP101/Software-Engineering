# Assignment 4 - FastAPI

This project is a simple API created using Python and FastAPI.

## Features
- GET requests to retrieve data.
- PUT requests to update item information.
- Uses Pydantic to validate data.

## How to Run
1. Install FastAPI and Uvicorn.
2. Run `uvicorn main:app --reload`.
3. Open `http://127.0.0.1:8000/docs` to test the API.
